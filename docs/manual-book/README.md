# Manual Book — Panel Admin Ekoteologi AR

Manual book ini memandu **tim admin, verifier, dan editor** dalam mengoperasikan
Panel Admin Ekoteologi AR sehari-hari: memverifikasi bukti misi pengguna,
mengelola misi dan konten harian, menyiapkan materi e-learning, hingga mengirim
pengumuman (push notifikasi).

Seluruh tangkapan layar pada manual ini diambil dari panel admin dengan data contoh,
sehingga angka yang tampil di layar Anda bisa berbeda.

## Cara Memakai Manual Ini

- **Baru bergabung sebagai admin/verifier/editor?** Baca Bab 1–2 terlebih dahulu,
  lalu bab sesuai tugas harian Anda (umumnya Bab 5).
- Setiap bab memuat: tujuan fitur, cara mengakses, langkah kerja bernomor,
  penjelasan kolom/field, dan catatan penting di akhir.
- Nama tombol, menu, dan label ditulis **persis seperti di layar** agar mudah
  dicocokkan. Istilah dalam `monospace` (mis. `fa-recycle`) adalah nilai yang
  diketik apa adanya.

## Ringkasan Sistem dalam Satu Paragraf

Ekoteologi AR adalah aplikasi mobile bagi pengguna muslim untuk memilah sampah
dengan bantuan scan AI, menyelesaikan misi lingkungan, membaca konten harian
(ayat/hadis/refleksi), dan belajar lewat modul e-learning berpoin. Panel Admin
(ini) adalah pusat kendali di sisi tim: hasil scan diproses **otomatis oleh AI**
(tanpa review admin), sedangkan **bukti foto misi**, **misi**, **konten harian**,
**materi e-learning**, dan **pengumuman** sepenuhnya dikelola dari panel ini.
